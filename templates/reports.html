1. Graph Theory Model

The hospital network is modeled as a directed multi-partite graph $G = (V, E)$, where vertex set $V$ is partitioned into disjoint subsets:

  • $V_P$: Patient nodes parameterized by urgency weight $w(p_i)$.
  • $V_D$: Department nodes acting as routing hubs.
  • $V_B$: Bed nodes representing physical hospital capacity.
Edge Weights: $w(P_i, D_j) = 4 - \text{PriorityLevel}(P_i)$
Matching Algorithm: Maximum Weight Bipartite Matching via NetworkX.
2. Priority Queue & Order Theory

Patient admission queue forms a strict total order under priority tuple $(L, T_{\text{adm}})$:

Emergency (Level 1) > Critical (Level 2) > General (Level 3)
Tie-breaker: FIFO ordering based on $T_{\text{adm}}$ timestamp.

Implemented using Python heapq min-heap invariant, guaranteeing $O(\log N)$ insertion and extraction time.

3. Set Theory Invariants

Bed state management enforces partition of Universal Set $U_{\text{Beds}}$:

Disjointness: $S_{\text{Available}} \cap S_{\text{Occupied}} \cap S_{\text{Maint}} = \emptyset$
Union Completeness: $S_{\text{Available}} \cup S_{\text{Occupied}} \cup S_{\text{Maint}} = U_{\text{Beds}}$
Formally Verified Live Invariant
4. Binary Relations & Functions

Bed allocation defines composite binary relations:

$R_{PD} \subseteq P \times D$ (Patient $\to$ Dept requirement)
$R_{DB} \subseteq D \times B$ (Dept $\to$ Bed containment)
Composite Mapping $R_{PB} = R_{PD} \circ R_{DB} \subseteq P \times B$

$R_{PB}$ is an injective function: Each allocated patient is mapped to at most one unique bed.
